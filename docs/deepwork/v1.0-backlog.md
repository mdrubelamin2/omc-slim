## Rulings

Every ruling taken on the caller's behalf. See the roll-up in the final message.

- **Keep `Task` in every `disallowedTools`, against the research lane's own
  recommendation.** The lane established that `Agent` is canonical and `Task` a
  legacy alias — then stated it had *not* traced the alias through the
  `disallowedTools` permission path specifically. One-level delegation is this
  plugin's only harness-enforced guarantee. Removing a redundant guard on it, to
  satisfy tidiness, on an untraced assumption, is the wrong side of "correctness
  first". `disallowedTools` costs zero static context, so the entry is free.
  What changes instead is the record: the 2026-08-25 audit called `Task` "a dead
  entry", and it is not dead — it is a live legacy alias. README says so.
- **Type-marking covers the model-facing set; agent bodies stay out of the gate.**
  Cross-cutting 1 asks for agent-body handoff sentences to carry a type word too.
  A gate predicate that must recognise "a line instructing onward routing" needs
  a keyword list, and a keyword list that misses one produces a GREEN gate over
  an unmarked handoff — worse than an honestly narrower scope. So the gate covers
  frontmatter descriptions, the output style, SKILL.md bodies, hook messages and
  README; I marked agent handoff sentences by hand, and the gate's own comment
  states the limit.
- **No type prefix on description openings.** The backlog asks that every agent
  description "open in a form unreadable as a skill". Six descriptions × a
  prefix is always-on static for a signal the Agent and Skill tool listings
  already carry structurally — and the observed misroute was a *cross-reference*
  (`deepwork` read out of prose as an agent), not a listing misread. The style's
  dispatch rule plus type-marked cross-references answer the observed failure;
  the prefix answers a hypothetical.
- **B9 — designer Review mode: cut the mode, keep the rule.** Neither
  keep-and-declare nor a plain cut. The mode contradicts the frontmatter and
  forces an unguaranteeable heuristic into a hook whose whole value is that it
  never cries wolf; but its pinned content (`designer-review-mode-locations`)
  is a *reporting* rule, not a mode — name the location and the measured number,
  never "consider improving accessibility". So the `## Review mode` section goes
  and the rule moves into designer's ordinary reporting. Frontmatter becomes
  true, the hook needs no heuristic, and
  `verify-deliverables.test.mjs`'s designer case stops being a pinned false
  positive and becomes a correct assertion. Costs: a caller wanting a
  critique-only UI audit routes to `review`'s Interface lane instead.
